# v0.1.4 Installed Release Smoke Fix

## Context

The v0.1.3 workflow verified source, tests, assets, and four platform builds, but
the post-publication Linux archive smoke exposed a release-mode blocker:
`bin/synapsis start` booted the OTP applications with the Phoenix endpoint
disabled. The same inspection found that `synapsis_mcp` and
`synapsis_sandbox` retained `0.1.0` in the embedded release manifest because
their Mix projects did not use the shared `@version` stamping convention.

The published `v0.1.3` tag remains immutable. This patch produces v0.1.4 only
after an installed Linux archive boots successfully before publication.

## Scope

- Enable `SynapsisServer.Endpoint` in production releases while retaining the
  default `127.0.0.1` bind and explicit `PHX_IP` opt-in.
- Normalize every umbrella Mix project to the existing `@version` release
  stamping contract.
- Add a pre-publication installed Linux archive smoke gate that checks the
  release/app versions, loopback socket, green health, and session creation.
- Document the Linux ERTS runtime-library prerequisites exposed by the NixOS
  verification host.
